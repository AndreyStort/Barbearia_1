Dicionário de Dados — Barbearia Ferrari

Entidade: Barbearia

Representa a organização responsável pelos funcionários, serviços, atendimentos e despesas cadastrados no sistema.

Atributo Descrição Tipo de Dado Regra de Negócio
PK id_barbearia Identificador único da barbearia. INT Deve ser único e obrigatório.
nome Nome da barbearia. VARCHAR(100) Campo obrigatório.
endereco Endereço da barbearia. VARCHAR(200) Campo obrigatório.
telefone Telefone de contato da barbearia. VARCHAR(20) Deve possuir formato válido.
responsavel Nome do responsável pela barbearia. VARCHAR(100) Campo obrigatório.

Entidade: Cliente

Representa os clientes que utilizam os serviços da Barbearia Ferrari.

Atributo Descrição Tipo de Dado Regra de Negócio
PK id_cliente Identificador único do cliente. INT Deve ser único e obrigatório.
nome Nome do cliente. VARCHAR(100) Campo obrigatório.
telefone Telefone do cliente. VARCHAR(20) Deve possuir formato válido.
data_cadastro Data em que o cliente foi cadastrado. DATE Preenchimento obrigatório.

Entidade: Funcionário

Representa os funcionários responsáveis pela realização dos serviços da barbearia.

Atributo Descrição Tipo de Dado Regra de Negócio
PK id_funcionario Identificador único do funcionário. INT Deve ser único e obrigatório.
FK id_barbearia Identifica a barbearia à qual o funcionário pertence. INT Deve estar associado a uma barbearia.
nome Nome do funcionário. VARCHAR(100) Campo obrigatório.
porcentagem Percentual recebido pelo funcionário sobre os serviços realizados. DECIMAL(5,2) Atualmente corresponde a 50%.
status Situação do funcionário. VARCHAR(20) Deve indicar se está ativo ou inativo.

Entidade: Serviço

Representa os serviços oferecidos pela Barbearia Ferrari e seus respectivos valores.

Atributo Descrição Tipo de Dado Regra de Negócio
PK id_servico Identificador único do serviço. INT Deve ser único e obrigatório.
FK id_barbearia Identifica a barbearia que oferece o serviço. INT Deve estar associado a uma barbearia.
nome Nome do serviço. VARCHAR(100) Campo obrigatório.
valor Valor cobrado pelo serviço. DECIMAL(10,2) Deve ser maior que zero.
tipo Categoria do serviço. VARCHAR(30) Pode identificar serviço tradicional ou químico.
status Situação do serviço. VARCHAR(20) Deve indicar se está disponível ou indisponível.

Entidade: Atendimento

Representa a realização de um serviço para determinado cliente, identificando o funcionário responsável e as informações relacionadas ao pagamento.

Atributo Descrição Tipo de Dado Regra de Negócio
PK id_atendimento Identificador único do atendimento. INT Deve ser único e obrigatório.
FK id_cliente Identifica o cliente relacionado ao atendimento. INT Deve estar associado a um cliente.
FK id_funcionario Identifica o funcionário responsável pelo atendimento. INT Deve estar associado a um funcionário.
FK id_servico Identifica o serviço realizado no atendimento. INT Deve estar associado a um serviço.
data Data em que o atendimento foi realizado. DATE Campo obrigatório.
hora Horário em que o atendimento foi realizado. TIME Campo obrigatório.
valor Valor cobrado pelo serviço. DECIMAL(10,2) Deve corresponder ao valor do serviço selecionado.
forma_pagamento Forma utilizada pelo cliente para realizar o pagamento. VARCHAR(20) PIX, dinheiro, débito ou crédito.
valor_funcionario Valor destinado ao funcionário responsável pelo atendimento. DECIMAL(10,2) Corresponde a 50% do valor do serviço realizado.

Entidade: Despesa

Representa os gastos necessários para o funcionamento da Barbearia Ferrari.

Atributo Descrição Tipo de Dado Regra de Negócio
PK id_despesa Identificador único da despesa. INT Deve ser único e obrigatório.
FK id_barbearia Identifica a barbearia à qual a despesa pertence. INT Deve estar associada a uma barbearia.
descricao Descrição da despesa. VARCHAR(150) Campo obrigatório.
categoria Categoria da despesa. VARCHAR(50) Ex.: aluguel, água, energia, internet ou material.
valor Valor da despesa. DECIMAL(10,2) Deve ser maior que zero.
data Data em que a despesa foi registrada. DATE Campo obrigatório.
tipo Classificação da despesa. VARCHAR(20) Deve ser fixa ou variável.
